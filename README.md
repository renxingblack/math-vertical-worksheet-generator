# math-vertical-worksheet-generator-加减乘除竖式出题器
A single-file HTML tool for generating primary school addition, subtraction, multiplication and division vertical worksheets. Supports A4 layout, multi-page segments, print/export, and JSON settings import/export.
# 加减乘除竖式出题器 单HTML工具 v2.0 · 用户手册

> 本手册按界面布局顺序编写，依次说明左侧控制面板、右侧预览区及各类弹窗的功能与使用方法。  
> 工具为纯前端单文件，所有数据在本地浏览器中处理，无需联网即可使用（导出图片/PDF/ZIP 时需联网加载组件）。

---

## 一、总体布局

界面分为左右两栏：

- **左侧控制面板**：所有出题、排版、显示、导出相关的参数设置。
- **右侧预览区**：实时显示 A4 页面效果，并提供缩放、翻页、导入/导出设置、打印等快捷操作。

控制面板中每个带 `▼` 的标题均可点击折叠/展开对应板块。

---

## 二、左侧控制面板

### 1. 多页分段设置

用于为不同页码范围保存不同的题目参数，实现一份文档内混合难度或混合运算类型。

| 控件 | 说明 |
|---|---|
| **启用多页分段** | 勾选后，下方列表中“启用”的分段使用其保存的设置；未启用分段及未覆盖的页面使用当前面板设置。 |
| **＋ 添加分段** | 新增一个分段。第一段起始页固定为 1；下一段起始页 = 上一段结束页 + 1。 |
| **总页数** | 整个文档的总页数，范围 1–200。修改后最后一段会自动延伸/截断。 |
| **分段列表** | 每行包含：起始页（不可编辑）、结束页（可编辑）、备注、启用勾选框、保存按钮、删除按钮。 |
| **保存** | 将当前控制面板的全部参数保存到该分段。之后该分段启用时即使用这套参数。 |
| **删除** | 删除该分段。至少保留一个分段。 |
| **启用** | 勾选后该分段生效；取消勾选时，该分段内的页面使用当前设置。 |

> 提示：第一段起始页始终为 1；若修改某段结束页大于总页数，会自动增加总页数。

### 2. 页面设置

控制纸张、方向、边距、字体与行列排布。

| 控件 | 默认值 | 说明 |
|---|---|---|
| **列数** | 3 | 每页题目列数，1–10。 |
| **排数** | 4 | 每页题目排数，1–10。 |
| **列间距** | 0 pt（自动） | 列与列之间的水平间距。勾选“自动”时由程序计算并填充。 |
| **排间距** | 0 pt（自动） | 行与行之间的垂直间距。勾选“自动”时由程序计算并填充。 |
| **字体** | 正文：宋体；西文：Courier New(等宽) | 正文与数字使用的字体。可分别选择。 |
| **字号** | 小四·12pt | 题目文字大小，从一号 26pt 到六号 7.5pt。 |
| **颜色** | #000000 | 题目文字颜色。 |
| **加粗** | 未勾选 | 题目文字是否加粗。 |
| **🖊 本机字体** | — | 点击后弹出字体检测窗口，可将检测到的本机字体应用到指定字体项。 |
| **当前排版** | — | 显示程序计算出的单元格尺寸、栏数、排数等信息，供调试参考。 |
| **方向** | 纵向 | 纸张方向：纵向 / 横向。切换后列数/排数会重置为 3×4（纵向）或 4×3（横向）。 |
| **纸张** | A4 | A4 / A3 / B5 / Letter。 |
| **边距** | 上 36、下 36、左 36、右 36（pt） | 页面四边留白，单位 pt。 |

> 自动调整：若排数或列数超出纸张可容纳范围，程序会自动减少排数/列数，并在控制台输出警告；预览区“当前排版”会显示实际值。

### 3. 题目设置

#### 3.1 难度与运算类别

| 控件 | 默认值 | 说明 |
|---|---|---|
| **难度** | 0.50 | 0 = 最难，1 = 最易。仅在未手动修改题目参数时，用于套用内置难度预设。 |
| **运算类别** | 加、减、乘、除全选 | 勾选哪些运算参与出题。勾选后下方会出现对应参数面板；取消勾选则隐藏该面板。 |
| **去除相同题目** | 勾选 | 同一多页分段内不允许出现相同题目。加/乘交换位置视为不同题目；减法/除法有序，不交换。 |
| **比例** | 勾选，加/减/乘/除均为 1 | 控制各运算在题目总数中的比例。 |

#### 3.2 加法竖式（两项）

| 区域 | 控件 | 说明 |
|---|---|---|
| 第1项 / 第2项 | 整数位 | 勾选“启用”后，可设置整数位数上限与数值范围。位数表示“不大于该位数”。 |
| | 小数位 | 勾选“启用”后，可设置小数位数上限与小数部分范围。“含少位”允许小数位数少于设定值。 |
| 和设置 | 整数位 / 小数位 | 对“和”的整数位、小数位、数值范围进行限制。 |
| 禁止末尾0 | 勾选 | 禁止加数或和的末尾出现可省略的 0。 |
| 禁止加数/和为1或0 | 勾选 | 禁止任何加数或和为 0 或 1。 |

#### 3.3 减法竖式（两项）

| 区域 | 控件 | 说明 |
|---|---|---|
| 差无负数 | 勾选 | 保证被减数 ≥ 减数，差不为负。 |
| 差无0 | 勾选 | 保证差不为 0。 |
| 第1项 / 第2项 | 同加法 | 分别设置被减数与减数的整数位、小数位与范围。 |
| 差设置 | 同加法 | 对差的整数位、小数位、范围进行限制。 |
| 禁止末尾0 | 勾选 | 禁止被减数、减数或差的末尾出现可省略的 0。 |
| 禁止被减数/减数/差为1或0 | 勾选 | 禁止任何一项或差为 0 或 1。 |

#### 3.4 乘法竖式（两因数逐位相乘）

| 区域 | 控件 | 说明 |
|---|---|---|
| 第1项 / 第2项 | 同加法 | 分别设置两个因数的整数位、小数位与范围。 |
| 积设置 | 同加法 | 对积的整数位、小数位、范围进行限制。 |
| 禁止末尾0 | 勾选 | 禁止因数或积的末尾出现可省略的 0。 |
| 禁止因数/积为1或0 | 勾选 | 禁止任何因数或积为 0 或 1。 |
| 自动交换乘数位置简算 | 勾选 | 自动将非零位数多的因数放在上方作为被乘数。 |
| 去除十百千万亿类乘数 | 未勾选 | 勾选后，若因数为不含小数的整数，则禁止其为 10 的幂。 |

#### 3.5 除法竖式

| 区域 | 控件 | 说明 |
|---|---|---|
| 整除 | 勾选 | 出整除题。 |
| 有余除法 | 勾选 | 出有余数除法题。 |
| 有限小数 | 勾选 | 出商为有限小数的题。 |
| 小数整除 | 勾选 | 出商为整数、但除数或被除数含小数的题。 |
| 除内部比例 | 勾选，四种类型均为 1 | 控制四种除法子类型在除法题目中的比例。 |
| 商设置 | 整数位 / 小数位 / 范围 | 对商的整数位、小数位与数值范围进行限制。 |
| 除数设置 | 整数位 / 小数位 / 范围 | 对除数的整数位、小数位与数值范围进行限制。 |
| 被除数设置 | 整数位 / 小数位 / 范围 | 对被除数的整数位、小数位与数值范围进行限制。 |
| 禁止末尾零 | 勾选 | 禁止被除数或商的末尾出现可省略的 0。 |
| 禁止除数/商为1或0 | 勾选 | 禁止除数为 0 或 1，禁止商为 0 或 1。 |
| 满足所有题目 | 仅当同时勾选“有限小数”和“小数整除”时显示 | 勾选后，小数整除题也会受商的小数位限制；不勾选则小数整除的商强制为整数。 |

> 所有面板中的“整数位”含义为“不大于该位数”。  
> “小数位”若未勾选“含少位”，则小数位数必须严格等于设定值；勾选后允许少于设定值。

## 四、弹窗说明

### 1. 本机字体选择弹窗

点击“🖊 本机字体”后弹出。  
- 顶部显示当前目标字体。  
- 可勾选“正文 / 西文 / 大标题 / 小标题 / 答案 / 页码 / 水印”多项。  
- 点击字体列表中的字体即应用到所选项目。  
- 支持 Chrome 等浏览器的 `queryLocalFonts` API；若不支持，则通过候选列表和 `document.fonts.check` 检测。

### 2. 范围无解警告弹窗

当题目参数相互矛盾、无法生成任何题目时，页面中央弹出红色警告框。  
- 标题：提示无满足条件题目，请修改值。  
- 详情：说明具体冲突原因。  
- 修改参数后弹窗自动关闭。

## 五、注意事项与技巧

1. **自动布局调整**  
   若设置的排数/列数超出纸张容量，程序会自动减少并在控制台输出警告。实际使用的排数/列数会显示在“当前排版”中。

2. **去除相同题目**  
   同一分段内判重。若题目空间不足，会尝试交换加数/乘数位置；仍无新题时该位置留空，待放宽范围后刷新会自动填充。

3. **难度滑条**  
   仅在未手动修改题目参数时，用于套用内置难度预设。一旦手动改动任一题目参数，难度滑条只作为题目抽取的偏向。

4. **分段设置**  
   每个启用分段保存独立的题目参数。未启用分段或未覆盖的页面使用当前左侧面板的设置。

5. **导出依赖网络**  
   图片版PDF、PNG、JPEG、SVG、Word、ZIP 导出需要联网加载 `html2canvas`、`jsPDF`、`JSZip` 等库。文字版PDF通过浏览器打印，无需额外加载。

6. **保存与恢复**  
   可通过“📤 导出设置”将全部参数保存为 JSON 文件；通过“📥 导入设置”恢复。

7. **打印页码**  
   打印时页码位置、格式与预览一致。若使用“对称页边距”，打印时也按奇偶页自动左右切换。
